# The plugin's native sources (bindings.cpp down to the SoLoud engine), for
# the test builds that link the whole plugin. One path or glob per line,
# relative to the repository root, in link order. A line starting with
# `apple:`, `android:`, `linux:` or `windows:` is only for that platform.
#
# Read by plugin_sources() in test/support/engine_sources.sh (the
# test/common, test/linux, test/macos, test/ios and test/android scripts,
# test/docker/windows_native.sh) and by Get-PluginSources in
# test/support/native_build.ps1 (test/windows). Not listed here, because each
# build picks them itself: src/pffft/pffft.c (compiled as C) and the audio
# backend (miniaudio, the Objective-C++ shim on Apple, or the null backend).
#
# hook/build.dart decides what the real plugin compiles:
# test/common/plugin_sources_test.dart fails when one of its sources is
# missing here. Platform-specific .cpp files under a glob compile to nothing
# on the other platforms.
